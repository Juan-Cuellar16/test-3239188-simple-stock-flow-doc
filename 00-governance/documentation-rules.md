# Documentation rules

> These rules support the challenge. The challenge README and supplied model take precedence over this supplemental file.

## 1. Language and format
- Write deliverable documents in English.
- Use the required folder names and filenames.
- Preserve canonical domain terminology and identifiers from the model.

## 2. Traceability
- Cite the model section, decision, access pattern, or consistency finding supporting each material claim.
- Mark claims not established by the model as [assumption].
- Distinguish engine-enforced, domain-only, and pending rules.

## 3. Source handling
- The challenge README defines required deliverables and submission rules.
- The supplied spec/data-model.md is the source for reconstructing the system documentation.
- Do not treat linked but undelivered documents as additional sources.
- Record model contradictions instead of silently resolving them.
- Do not modify or replace the supplied model.

## 4. Scope
Do not present unsupported technologies, interfaces, roles, service levels, or business rules as facts. Keep explicit exclusions visible, including customer data, multi-currency, seller report breakdown, and additional product attributes (D-05, DP-02/03, model §§1 and 12).
